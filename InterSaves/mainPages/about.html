Inscription Connexion

1. Qu'est ce qu'une save ?

Une save est un fichier de sauvegarde d'un jeu. C'est ce fichier qui contient votre progression dans le jeu, vos objets, votre équipement, etc... C'est grâce à ce fichier que vous pouvez reprendre votre partie là où vous l'avez laissé.

2. Comment partager une save ?

Pour partager une save il vous suffit de vous inscrire sur notre plateforme, de créer un compte et de suivre les instructions pour uploader votre save. Une fois votre save uploadé vous pourrez la partager avec vos amis en leur donnant le lien de votre save.

3. Comment utiliser une save partagée ?

Pour utiliser une save partagée il vous suffit de cliquer sur le lien de la save que vous souhaitez utiliser, de télécharger le fichier de la save et de le placer dans le dossier de sauvegarde de votre jeu. Une fois que vous avez placé la save dans le dossier de sauvegarde de votre jeu vous pourrez reprendre la partie là où la personne qui a partagé la save l'a laissé.

4. Quels jeux sont compatibles ?

Notre plateforme est compatible avec tous les jeux en multijoueurs local qui utilisent des fichiers de sauvegarde pour stocker la progression des joueurs. Cependant, certains jeux peuvent avoir des formats de sauvegarde spécifiques qui ne sont pas encore pris en charge par notre plateforme. Nous travaillons constamment à ajouter la compatibilité avec de nouveaux jeux, donc n'hésitez pas à nous contacter si vous souhaitez voir un jeu spécifique ajouté à notre plateforme.

5. Et la sécurité ?

Tous les fichiers de sauvegardes sont annalysé avant chaque upload sur nos serveurs et sont marqués si ceux si sont potentionnelement indésirable. Nous nous efforcons de fournir une plateforme securitaire et fiable pour nos utilisateurs.
